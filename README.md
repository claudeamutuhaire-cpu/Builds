## What's Included

### Pages
- `index.html` — Home
- `about.html` — About / Mission / Vision / Values
- `services.html` — All 9 services in detail
- `portfolio.html` — **Premium 3D shutter before/after transitions** + team + product + app screenshots

- Real HuntArts geometric wolf logo

## How to Upload to GitHub

1. Go to your **Builds** repository (or create a new one)
2. Upload **everything** inside this folder (all .html files + the entire `assets` folder)
3. Connect the repository to Vercel for instant live deployment
